# paralleldots-ML-Assignment
An end-to-end retail shelf pipeline for OSA and SOS tracking. It pairs YOLOv8 for high-density product localization with OpenAI's CLIP for dynamic, zero-shot brand classification without data-labeling bottlenecks. Bypasses heavy networks using a 1D DBSCAN clustering heuristic to segment rows and extract prices via EasyOCR.
